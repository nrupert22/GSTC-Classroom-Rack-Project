# About
This is public documentation of a full size server rack in the Network Systems program classroom at George Stone Technical College. Project started by Sebastian Thrasher and Nathan Rupert and overseen by the course instructor Derrick Beaird. 

On this project page you will find files containing layouts of hardware or network topology but also running scripts or configurations used. 

# Purpose
This projects purpose and main goal is to apply knowledge accumulated through the NSS course and demonstrate knowledge of best practice for systems administration, backups, restoration, deployment, and networking. We felt it was important to demonstrate these skills on physical hardware starting from hardware assembly and planning then eventually moving to running services for documentation or class use.
